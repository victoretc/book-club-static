«Читка» — статический сайт, реализованный при помощи Hugo, хостится при помощи GitHub Pages. Книги добавляются вручную. Если хотите предложить книгу — создайте Issue на GitHub в соответствии с шаблоном. После проверки она появится в каталоге.
