# Идеи нового функционала

## Личное — «моя полка»

1. **Статусы чтения** вместо одного «избранного»: читаю / прочитал /
   в планах, с прогрессом страниц. Хранится в localStorage, плюс
   экспорт/импорт JSON — чтобы не потерять при смене браузера.
2. **История и статистика**: «в этом году ты прочитал 12 книг», полка
   за год. Мотивирует возвращаться.
3. **Случайная рекомендация** — кнопка «Выбери мне книгу» в каталоге:
   фильтрует по твоим статусам и выдаёт одну карточку.

## Социальное — через GitHub как бэкенд

4. **Отзывы + рейтинг клуба** (схема уже заложена с
   `review_request.yml`): агрегированная оценка на карточке, сортировка
   клубов по рейтингу.
5. **Голосование за следующую книгу** в клубе — Issue с label,
   reactions как голоса, Action считает и публикует результат на
   странице клуба.
6. **Подборки-редактуры** (curated): «Клубы для новичков в тестировании»,
   «Авторские клубы, с которых начать» — рукописный список в `data/`,
   сильно поднимает конверсию при пустом каталоге.

## Вовлечение

7. **Календарь чтения**: даты встреч клуба в front matter → блок
   «Ближайшая встреча» + ICS-подписка в календарь.
8. **Блог** — анонсы новых клубов, итоги месяца, обзоры. Даёт
   SEO-трафик, которого сейчас нет (у сайта один запрос — «найти клуб»).
9. **Страница-лендинг для каждой категории**: «Клубы по тестированию»
   с вводным текстом, а не пустой список.

## Рост

10. **Страницы авторов и книг отдельно** (кластер): сейчас одна
    страница клуба — один URL. Страница книги = больше поисковых входов.
11. **RSS-рассылка «новые клубы»** — на Hugo нативно, почти бесплатно.

## Геймификация

12. **Челлендж года** — «Прочитай 12 книг за год»: бейджи и витрина
    прогресса на основе твоей полки (localStorage). Бейджи можно
    «делиться» ссылкой-карточкой.
13. **Серии и марафоны** — «Ноябрьский марафон: 30 дней, 30 глав»:
    тематические цепочки клубов, единый прогресс.
14. **Достижения за отзывы** — «Первый рецензент», «Читатель-
    энциклопедист» (10 отзывов). Стимул писать.

## Контент-инструменты

15. **Генератор «книжной полки»** — вводишь прочитанные книги,
    получаешь красивую картинку-полку для шаринга в соцсетях. Вирусный
    рост без бэкенда: всё рисуется в canvas/SVG на клиенте.
16. **Тесты-подборщики** — «Какой книжный клуб тебе подходит?»
    (5 вопросов → категория/клуб). Классика для лендинга, высокий
    доскролл.
17. **Цитаты недели** — карточка с цитатой из описания клуба/книги,
    кнопка «Скопировать». Маленький, но клевой контент для соцсетей.
18. **Словарь книжного клуба** — «что такое бета-чтение, шеринг, разбор»:
    привлекает новичков через поиск, снижает порог входа.

## Поиск и навигация

19. **Фасеты «наоборот»** — не «выбери категорию», а «у меня 2 часа в
    неделю / хочу читать по 300 страниц / группа 10+ человек» → фильтр
    по параметрам клуба.
20. **Сравнение клубов** — 2–3 карточки рядом: размер, темп, формат
    (озвучка/текст/встречи), рейтинг. Помогает выбрать.
21. **«Рядом со мной»** — фильтр по городу/языку, если клубы офлайн-
    или региональные.

## Формат

22. **Аудио-обзоры / подкаст-страница** — у клуба может быть свой
    подкаст; отдельный плеер-блок на странице.
23. **Формат «одна книга — один клуб» vs «постоянный клуб»** — фильтр
    по жизненному циклу: разовый (присоединился — читаешь одну) или
    постоянный. Сейчас `club_type` делит на book/author, а это другое
    измерение.
24. **Страница-«витрина месяца»** — редакторский выбор: один клуб на
    главной с обложкой и цитатой. Держит главную живой.

## Социальное (доп.)

25. **Реакции «хочу читать»** — не избранное (личное), а публичный
    счётчик интереса. Через GitHub reactions, считает Action.
26. **«Кто ещё читает»** — агрегатор: участники из `member_names` →
    общий список читателей с перелинковкой между клубами. Нетворк-
    эффект: «Виктор читает в 3 клубах».
27. **Приглашение в клуб по ссылке** — UTM-ссылка с клуба: «Приведи
    друга» → статистика приглашений.

## Техническое, но заметное

28. **OG-картинки по динамике** — генерировать превью клуба с
    названием и рейтингом (Hugo + SVG/Action) вместо общего
    `og-default.png`: шаринг в TG выглядит на порядок лучше.
29. **Оффлайн/PWA-манифест** — сайт-каталог открывается как приложение
    на телефоне, полка работает без сети.

## Топ по соотношению эффект/усилия

1. **Отзывы с рейтингом** — данные уже спроектированы.
2. **Подборки** — заполняют пустой каталог сразу.
3. **Случайная рекомендация** — дёшево, цепляет.
4. **Генератор книжной полки** — виральность.
5. **Тест-подборщик** — лендинг.
6. **Страница-витрина месяца** — оживление главной.
7. **Сравнение клубов** — реальная боль выбора.
