# Лэндинг для «Читальной» — план и тексты

Файл-размышления по лендингу на главной (`/`), над существующим каталогом.
Структура: сначала ответы на вопросы frameworks (цели, аудитория), потом
секции страницы с готовыми текстами, потом технический план реализации.

---

## Блок 1. Для чего делаем лендинг (вопросы к себе)

| Вопрос | Ответ для «Читальной» |
|---|---|
| **Бизнес-цель** | Не продажа. Ключевое действие: пользователь нашёл клуб и перешёл в его Telegram-чат. Долгосрочно — чтобы клубы добавляли сами (заявка на добавление). |
| **Целевая аудитория** | Читатели, которые хотят читать в кругу, но не знают, где найти клуб. Пока ниша: тестирование, дизайн (категории из `data/categories.yml`). Преимущественно мобайл. |
| **Оффер** | Бесплатный каталог книжных клубов: описание книги, участники, ссылка на чат. Без регистрации. Отличие: клубы размечены по типам (по книге / авторские) и категориям — а не просто «чат в телеге». |
| **Одна главная CTA** | «Найти клуб» → якорь на каталог ниже. |
| **Откуда трафик** | SEO (Hugo, статика) + Telegram/соцсети. SEO любит контент — FAQ и описания нужны, но без воды. |
| **KPI успеха** | Клик из хиро в каталог → открытие карточки клуба → переход по Telegram-ссылке. Позже: число заявок на добавление клуба. |
| **Что после клика** | Якорь вниз к каталогу → карточка клуба → чат. Никаких форм, мгновенный результат — список клубов. |
| **Ограничения** | Статика: нет регистрации, бэкенда, модерации. Контента мало — 1 клуб, 2 категории. GitHub-issue для добавления клуба — барьер для не-разработчиков. |

## Блок 2. На какие вопросы пользователя отвечает лендинг

| Вопрос пользователя | Ответ лендинга |
|---|---|
| Что это и мне ли это? | Каталог книжных клубов. Для тех, кто хочет читать вместе. Не для тех, кто ищет аудиокниги или курсы. |
| Зачем мне это? | Одиночное чтение: нет дедлайна, нет с кем обсудить. Клуб даёт чат и круг единомышленников. |
| Почему вам можно верить? | В каждой карточке реальные участники и живая ссылка на чат. (Отзывы и цифры — когда появятся, сейчас врать нечего.) |
| Чем вы лучше альтернатив? | Поиск клубов в Telegram и поисковиках хаотичен. Здесь разметка: тип, категория, книга. |
| Сколько это стоит? | Бесплатно. Скрытых платежей нет — их физически нет. |
| Как это работает? | 3 шага: выбрать → открыть карточку → зайти в чат. |
| Какие риски? | Ничего не вводишь — нет регистрации, значит нет данных под угрозой. Избранное хранится в браузере (localStorage). |
| Что мне сделать дальше? | Кнопка «Найти клуб» → каталог. |
| Можно ли доверять сайту? | Открытый репозиторий на GitHub, есть политика конфиденциальности. |

## Секции лэндинга (порядок на странице `/`)

Лэндинг живёт на `/` **над существующим каталогом** — ссылки и SEO не
ломаются, каталог остаётся ниже. Порядок секций:

### 1. Хиро

Голос: прямо, кто мы и что даём, без поэзии.

> **Каталог книжных клубов**
>
> Выбери клуб по книге или автору — в карточке описание, участники
> и ссылка на чат. Бесплатно и без регистрации.
>
> [Найти клуб] · [Добавить клуб]

- Кнопка 1 — якорь `#catalog` (главная CTA)
- Кнопка 2 — GitHub issue `book_request.yml` (уже есть в меню)
- Визуал: полка с корешками / стопка книг (в стиле `later/BOOK-AESTHETIC-PLAN.md`)

### 2. Цифры (честные, считаются из данных в шаблоне)

> 1 клуб · 2 категории · без регистрации

- Считать из `site.RegularPages` (секция clubs) и `data/categories.yml`,
  не вписывать руками
- Пока клуб мало — не растягивать блок, при желании скрыть

### 3. Витрина каталога

- Первые 4–6 карточек клубов — переиспользовать `partials/club-card.html`
- Чипы категорий — как в `partials/catalog.html`
- Всё ведёт в каталог ниже

### 4. Как это работает (3 шага)

1. Выбери категорию или найди клуб поиском
2. Открой карточку: книга, участники, ссылка на чат
3. Заходи в чат — читай вместе

### 5. Два типа клубов (2 колонки)

- **По книге** — клуб собирается вокруг одной книги
- **Авторские** — «в разработке, проголосовать на GitHub»
  (ссылка на issue #1 уже есть в коде)

### 6. FAQ

Прямые ответы, без воды:

- **Сколько стоит?** Ничего. Каталог бесплатный.
- **Нужна регистрация?** Нет — нечего регистрировать.
- **Как вступить в клуб?** Карточка → ссылка на Telegram-чат.
- **Как добавить свой клуб?** Заявка через GitHub.
- **Отзывы кто пишет?** Участники клубов; правила модерации — в планах.

### 7. Финальный CTA

> **Найди свой клуб сегодня**
>
> [Найти клуб] → якорь на каталог

### 8. Каталог (существующий) → футер

- Каталог не трогаем, он идёт ниже лэндинга
- Футер — колофон-экслибрис из `BOOK-AESTHETIC-PLAN.md` (п. 16)

### Отложено

- **Отзывы участников** — отзывов в данных пока нет, не делать
  до появления контента

## Технический план реализации

### Файлы

1. `layouts/partials/landing.html` — новый патиал, все 7 секций и тексты
2. `layouts/home.html` — подключить `landing.html` перед `catalog.html`
3. CSS секций — в текущий бандл или отдельный `landing.css`
   в стиле `BOOK-AESTHETIC-PLAN.md`: кремовая бумага `#F7F3EA`,
   Drabina в заголовках, хвостовики (п. 12), флероны-разделители (п. 10)
4. Цифры — шаблонные выражения из `site.RegularPages` + `data/categories.yml`

### Особенности

- CTA ведут якорями вниз — навигация и `menu` не меняются
- Проверка сборки: `hugo --minify --gc` без ошибок
- Ловушки Hugo 0.150: один `return` на шаблон, `relURL` без ведущего слэша
- Секции на мобиле складываются в одну колонку; витрина использует
  существующий grid клубов

### Порядок работ

1. Тексты секций согласованы (этот файл)
2. `landing.html` — разметка всех секций
3. Подключение в `home.html`
4. Стили
5. Считалка цифр
6. `hugo --minify --gc` + просмотр на мобиле/десктопе

## Риски

- **Витрина из 1 клуба выглядит пустой.** Варианты: сначала наполнить
  каталог, либо честно писать «каталог растёт — добавь первый клуб».
- **GitHub-issue для добавления клуба** — барьер для не-разработчиков.
  Пока принимаем, в FAQ честно указываем способ.
- **Отзывов и крупных цифр нет** — не выдумывать, блоки скрывать
  до появления данных.
